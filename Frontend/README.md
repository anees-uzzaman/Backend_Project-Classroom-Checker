# Classroom Checker

A modern React application designed to streamline classroom availability checks, booking management, and routine updates within an educational institution.

🔗 **[View Live Demo](https://new-eta-pink.vercel.app/)**

---

## 🚀 Features

* **Room Availability Checker**: Filter classrooms dynamically by day, time, capacity, AC availability, projectors, and lab equipment.
* **Booking Management**: Seamlessly manage room bookings equipped with confirmation dialogs.
* **Routine Updates**: Submit and manage academic routine adjustments efficiently.
* **User Profile Management**: Integrated user profile section featuring an intuitive edit mode.
* **Responsive Navigation**: Fully responsive sidebar navigation optimized for various screen sizes.

---

## 🛠️ Tech Stack

* **Frontend Library**: React
* **Styling Framework**: Tailwind CSS
* **Language**: JavaScript (ES6+)
* **Deployment**: GitHub Pages & Vercel

---

## 📋 Prerequisites
